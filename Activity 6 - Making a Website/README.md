

# Activity 6 - Making a Website

## Activity Description

This activity focused on creating a personal portfolio website using artificial intelligence (AI) tools. I designed a one-page website that reflects my personality, interests, and experiences as a nursing student. The website features my travels, friendships, hobbies, and nursing life through personal photographs, creative layouts, and an elegant design. This activity allowed me to explore AI-assisted website development and digital self-expression.

## What Have I Learned?

Through this activity, I learned how to use AI tools and detailed prompts to create and customize a website according to my preferred layout, colors, and overall aesthetic. I also gained a better understanding of website design, visual organization, and the importance of providing clear instructions when using artificial intelligence. One challenge I encountered was achieving my desired website design because I had limited experience in web development. However, I overcame this by refining my prompts, adjusting design elements, and experimenting with different instructions until I achieved a satisfactory result. In the future, I can apply these skills to create professional digital portfolios, showcase academic achievements, and develop more interactive websites while continuously improving my technological and creative abilities.
